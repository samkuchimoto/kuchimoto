[01] Platform Engineering / Consumer PWA

Ittsui France一対

An anti-calendar relationship ritual platform, engineered to protect real human connection against schedule decay. One proposal a week, one tap to confirm, and silence in between. The invited party needs no account and no install — the invitation is a plain web link, which is also the product’s entire distribution model. A single TypeScript codebase ships the web app, the installable PWA, and native iOS and Android builds.

[02] Developer Infrastructure / Compliance Automation

Kuchimoto Play Telemetry

A managed closed-testing platform for Google Play’s mandatory 14-day production access requirement — real human testers on real devices, not the synthetic bot rings that risk account termination under Google’s own manual review. An interactive live-cohort dashboard renders per-device session activity and a 14-day telemetry curve against Google’s real tester floor, backed by a structured CSV/JSON export of every session, ready to attach to a Production Access application.

Stack
Next.js 16 · React 19 · TypeScript · Tailwind v4 · Framer Motion · Vercel Edge
Engineering
Interactive cohort telemetry dashboard, capacity-based tester allocation model, CSV/JSON session export, Google-Groups-based closed-testing onboarding

[01 / Zero No-Code]

You own the source

No Webflow, no Bubble, no Squarespace. Every platform is written in clean, maintainable TypeScript on modern web primitives. You own 100% of the codebase and can hand it to any engineer on earth.

[02 / Sub-Second Performance]

Measured, not asserted

Both deployments above paint in well under half a second from a cold cache — the figures on each card are real measurements, median of three runs, not targets. Zero asset bloat, aggressive edge caching.

No account managers, no junior subcontractors, no agency markup. You interface directly with the engineer designing, writing and shipping your codebase.
